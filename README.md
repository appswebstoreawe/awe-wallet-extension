# AWE Wallet

AWE Wallet is a browser extension for Ethereum, BNB Chain and Solana.

## Features

- Create a new wallet
- Import an existing wallet
- Manage multiple accounts
- Ethereum support
- BNB Chain support
- Solana support
- View token balances
- Send and receive crypto
- Swap supported assets
- Import tokens
- View transaction activity
- Popup and side-panel wallet interface

## Website

https://www.appswebstore.com/create-wallet/

## About

AWE Wallet provides a simple self-custody multi-chain wallet experience for managing supported crypto assets across Ethereum, BNB Chain and Solana.

Users remain responsible for protecting their wallet credentials and approving blockchain transactions.

## Supported Networks

- Ethereum
- BNB Chain
- Solana

## Disclaimer

Cryptocurrency transactions involve risk. Always verify wallet addresses, network fees and transaction details before confirming.
